# tl_ble_sdk
Telink BLE SDK for TL series Bluetooth Low Energy chips.

## Supported Chips
- TLSR921X (B91)
- TLSR922X / TLSR952X (B92)
- TL721X
- TL321X
- TL322X
- TL323X

## Toolchain & IDE Version
| Chip Series       | Toolchain                          | GCC Version | IDE                          |
|-------------------|------------------------------------|-------------|------------------------------|
| TLSR921X (B91)    | TL32 ELF MCULIB V5F                | GCC 7.4     | TelinkIoTStudio              |
| TLSR922X/TLSR952X | TL32 ELF MCULIB V5F                | GCC 12.2    | TelinkIoTStudio              |
| TL721X            | TL32 ELF MCULIB V5F                | GCC 12.2    | TelinkIoTStudio              |
| TL321X            | TL32 ELF MCULIB V5                 | GCC 12.2    | TelinkIoTStudio              |
| TL322X            | TL32 ELF MCULIB V5F                | GCC 12.2    | TelinkIoTStudio              |
| TL323X            | TL32 ELF MCULIB V5F                | GCC 12.2    | TelinkIoTStudio              |

- IDE Download: [TelinkIoTStudio](https://www.telink-semi.com/development-tools)
